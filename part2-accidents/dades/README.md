# Dades per al projecte

El CSV no s'inclou en aquest repositori perquè és un recurs pesat i es pot
descarregar de la seva font oficial:

- [Accidents gestionats per la Guàrdia Urbana. Causes de conductor — Open Data BCN](https://opendata-ajuntament.barcelona.cat/data/ca/dataset/accidents_causa_conductor_gu_bcn)

Per al curs 2026-2027:

1. Obre el conjunt de dades.
2. Localitza el recurs corresponent a l'any **2025** en format CSV.
3. Descarrega'l al teu ordinador.
4. Obre `index.html` i selecciona el fitxer descarregat amb el control de
   càrrega.

No renomenis, edites ni converteixis les capçaleres del fitxer abans d'utilitzar
la primera vegada l'aplicació. Així podràs comprovar que el carregador
identifica les columnes pels seus noms i no per la seva posició.

Si necessites conservar una còpia local dins d'aquesta carpeta, Git l'ignora per
evitar publicar dades pesants o còpies duplicades.
